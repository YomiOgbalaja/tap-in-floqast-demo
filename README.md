# Tap In — FloQast Demo Build

This is a **demo build** of the Tap In people-analytics platform, visually themed with colors and typography inspired by [floqast.com](https://www.floqast.com/) for an employee-population walkthrough.

- **Product name stays "Tap In"** — this is not an official FloQast product, and no FloQast logo or trademark assets are used.
- **All data is simulated** — this workspace is not connected to a real HRIS or to any FloQast system.
- The unbranded master/source version of Tap In lives at [Tap-in-version-1](https://github.com/YomiOgbalaja/Tap-in-version-1).

Live demo: https://yomiogbalaja.github.io/tap-in-floqast-demo/
